- **Shared Rides** - Total carpools joined

- Social proof

### 4. **Live Crowd Meter** 🚍
**Location:** `/crowd-meter`

**Features:**
- **Real-time Crowd Levels** - Empty, Moderate, Crowded, Packed
- **Visual Progress Bars** - Color-coded (green → red)
- **Quick Report System** - One-tap emoji reporting
- **Smart Recommendations** - "Avoid this bus" or "Good time to board"
- **Next Bus Timer** - Minutes until next bus

**Report Options:**
- 😊 Empty (0-25%)
- 🙂 Moderate (25-50%)
- 😐 Crowded (50-75%)
- 😰 Packed (75-100%)

**Viral Mechanics:**
- Unique feature (Google Maps doesn't have this)
- Extremely useful
- Shareable screenshots
- Network effects (more users = better data)

**Why It's Viral:**
Solves a real pain point. Users will share screenshots saying "Saved me from a packed bus!" Friends will install to get the same benefit.
